ข้อมูลไม่ออกจากเครื่องนี้

ไฟล์ Data Exchange มีเลขบัตรประชาชนและข้อมูลระบุตัวบุคคล หน้านี้จึงออกแบบให้ทำงานในเบราว์เซอร์ของท่านเท่านั้น

  • ไฟล์ Excel ถูกอ่านและคำนวณในเครื่องนี้ ไม่มีการอัปโหลดไปที่ใด
  • หน้านี้ถูกล็อกไม่ให้เชื่อมต่ออินเทอร์เน็ตด้วย Content-Security-Policy ใช้งานได้แม้ถอดสาย LAN
  • เก็บเฉพาะคอลัมน์ผลตรวจที่ใช้คำนวณ ไม่เก็บชื่อ สกุล เลขบัตร ที่อยู่ ข้อมูลรายบุคคลอยู่ในหน่วยความจำชั่วคราว ปิดหน้านี้แล้วหายทั้งหมด
  • เบราว์เซอร์จำไว้เฉพาะตัวเลขสรุปของรายงานล่าสุด (ระดับหน่วยบริการ ไม่มีข้อมูลรายบุคคล) เพื่อเปิดดูซ้ำได้ทันที กดล้างได้ทุกเมื่อ

2. สร้าง Dashboard

เลือกไฟล์อย่างน้อย 1 ไฟล์ และระบุกลุ่มอายุให้ครบทุกไฟล์

วิธีส่งออกข้อมูลจาก HDC
  1. เข้าระบบ HDC แล้วเปิดรายงานตามกลุ่มอายุในตารางด้านล่าง
  2. กดปุ่มส่งออกแบบ Data Exchange (ไม่ใช่ปุ่มส่งออกตารางสรุป) เพราะต้องใช้ข้อมูลรายบุคคลที่มีผลตรวจฟันครบ
  3. ข้อมูลระดับจังหวัดที่ HDC แบ่งเป็นไฟล์ละ 100,000 รายการ เลือกมาทุกไฟล์ได้เลย
  4. ไม่ต้องแก้หัวตารางหรือชื่อไฟล์ ถ้าชื่อไฟล์หรือโฟลเดอร์ไม่มีเลขอายุ โปรแกรมจะเดาจากคอลัมน์ age_y ให้ ตรวจดูอีกครั้งในช่องกลุ่มอายุ
