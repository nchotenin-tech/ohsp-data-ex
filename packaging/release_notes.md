## ใหม่ในเวอร์ชัน 2.1.1: ชุดโฟลเดอร์มาตรฐาน และระบุกลุ่มอายุแม่นขึ้น

* ไฟล์ `Dashboard-HdcOralStatus-vX.Y.Z.zip` แตกแล้วได้โฟลเดอร์มาตรฐานพร้อมใช้ (ไฟล์ HTML + data\3ปี 6ปี 12ปี 60ปี)
* โปรแกรมระบุกลุ่มอายุจากรหัสรายงานในชื่อไฟล์ HDC และตรวจซ้ำจากข้อมูลในไฟล์
(แก้ปัญหาเวอร์ชัน 2.0–2.1 ที่ไฟล์ 18.3 ของกลุ่ม 6 ปีถูกเดาเป็น 3 ปีเมื่อเลือกไฟล์โดยไม่มีโฟลเดอร์)

## เวอร์ชัน 2.1: เปิดโปรแกรมแล้วเห็นรายงานล่าสุดทันที

เบราว์เซอร์จำตัวเลขสรุปของรายงานล่าสุดไว้ (ไม่มีข้อมูลรายบุคคล) ไม่ต้องเลือกไฟล์ Excel ใหม่ทุกครั้ง
นำเข้าข้อมูลชุดใหม่เมื่อไรก็ได้ และกด **ล้างรายงานที่จำไว้** ได้เมื่อใช้เครื่องร่วมกับผู้อื่น

## เวอร์ชัน 2.0: เปิดด้วยเบราว์เซอร์ ไม่ต้องติดตั้ง

โปรแกรมเปลี่ยนจากไฟล์ .exe เป็น **ไฟล์ HTML ไฟล์เดียว** แก้ปัญหา Windows 11 (SmartScreen / Smart App Control) บล็อกโปรแกรม
ผลคำนวณเหมือนเวอร์ชัน 1.2.0 ทุกตัวเลข (ทดสอบเทียบกันอัตโนมัติทุกครั้งที่ปล่อยเวอร์ชัน) และเร็วขึ้นหลายเท่า

## วิธีใช้งาน

**1. ดาวน์โหลด** `Dashboard-HdcOralStatus-vX.Y.Z.zip` จากหัวข้อ Assets ด้านล่าง แล้วคลิกขวา > Extract All

```
Dashboard-HdcOralStatus\
├─ OHSP-Dashboard-vX.Y.Z.html    ← ดับเบิลคลิกเปิดด้วย Chrome หรือ Edge
├─ อ่านก่อนใช้งาน.txt
└─ data\
   ├─ 3ปี\     ← รายงาน 18.2
   ├─ 6ปี\     ← รายงาน 18.3
   ├─ 12ปี\    ← รายงาน 18.5
   └─ 60ปี\    ← รายงาน 18.11 (หลายไฟล์ได้)
```

**2. ส่งออกข้อมูลจาก HDC** แบบ **Data Exchange** การตรวจฟัน (ไม่ใช่ปุ่มส่งออกตารางสรุป)

| กลุ่มอายุ | ชื่อรายงานใน HDC |
|---|---|
| 3 ปี | 18.2 OHSP ร้อยละเด็กกลุ่มอายุ 3 ปีมีฟันผุในฟันน้ำนม |
| 6 ปี | 18.3 OHSP ร้อยละเด็กกลุ่มอายุ 6 ปีมีฟันผุในฟันแท้ |
| 12 ปี | 18.5 OHSP ร้อยละเด็กกลุ่มอายุ 12 ปีมีฟันผุในฟันแท้ |
| 60 ปีขึ้นไป | 18.11 OHSP ร้อยละของผู้สูงอายุ ที่มีฟันแท้ใช้งานได้ไม่น้อยกว่า 20 ซี่ |

ข้อมูลที่ HDC แบ่งเป็นไฟล์ละ 100,000 รายการ เก็บมาทุกไฟล์ โปรแกรมต่อให้เอง
วางไฟล์ลงโฟลเดอร์ `data` ตามกลุ่มอายุ **ไม่ต้องเปลี่ยนชื่อไฟล์** ได้ข้อมูลชุดใหม่ให้ย้ายไฟล์ชุดเก่าออกก่อน โปรแกรมดูกลุ่มอายุจากรหัสรายงานในชื่อไฟล์ (18.2 / 18.3 / 18.5 / 18.11) และตรวจซ้ำจากคอลัมน์ age_y ในข้อมูล
ถ้ามีโฟลเดอร์ `data\3ปี 6ปี 12ปี 60ปี` เดิมจากเวอร์ชัน .exe ก็ใช้ได้เช่นกัน

**3. ดับเบิลคลิกไฟล์ HTML** ให้เปิดใน Chrome หรือ Edge กด **เลือกทั้งโฟลเดอร์** แล้วเลือกโฟลเดอร์ `data`
(หรือลากไฟล์ .xlsx มาวาง) ตรวจช่องกลุ่มอายุ แล้วกด **สร้าง Dashboard**

**4. ครั้งต่อไป** เปิดไฟล์ HTML จะเห็นรายงานล่าสุดทันที ถ้าต้องการส่งต่อ กด **บันทึกรายงานเป็นไฟล์** ได้ไฟล์ .html ที่มีแต่ตัวเลขสรุป

## ข้อมูลส่วนบุคคล

* ไฟล์ Excel ถูกอ่านและคำนวณ **ในเบราว์เซอร์ของเครื่องนั้น** ไม่มีการอัปโหลด
* หน้าเว็บ **ถูกล็อกไม่ให้เชื่อมต่ออินเทอร์เน็ต** ด้วย Content-Security-Policy ใช้งานได้แม้ไม่มีเน็ต
* ไม่เก็บชื่อ สกุล เลขบัตร ที่อยู่ ข้อมูลรายบุคคลอยู่ในหน่วยความจำชั่วคราว ปิดแท็บแล้วหายทั้งหมด
* เบราว์เซอร์จำไว้เฉพาะตัวเลขสรุปของรายงานล่าสุด กดล้างได้ทุกเมื่อ
* รายงานและ CSV ที่ดาวน์โหลดมีแต่ตัวเลขสรุประดับหน่วยบริการ
